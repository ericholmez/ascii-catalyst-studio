# Roadmap

## v0.5

Source preparation includes four-corner perspective correction, crop and aligned comparison, a five-point tone curve, texture filters, and automatic and painted masks. Palette extraction and custom palette controls are the next conversion milestone.

## Conversion and diagnosis

- Expand tone mapping, palette extraction, custom palettes, and independent colour dithering.
- Add contour continuity, multi-cell optimization, adaptive Braille, quarter blocks and connected box drawing.
- Add glyph priorities, editable density charts and more detailed diagnostics.
- Validate glyph coverage against font character maps and broaden the bundled Unicode repertoire.

## Composition and typography

- Add image, adjustment, mask, procedural and reference layers, groups and locks.
- Add brush sizing, selection, fill, line and shape tools, replacement, and compatible text flattening.
- Extend fixed text placement, word preservation, proportional layouts, contour-following layouts, and text-file import.
- Add more per-section resets, adjustable panels and configurable shortcuts.

## Motion and release quality

- Add temporal continuity, keyframes, image sequences, source timing, and adaptive frame pacing.
- Add animated GIF, frame sequence, and animated HTML export. Evaluate optional MP4 encoding.
- Add an accessibility audit, automated browser matrix, reference image evaluation and mobile benchmarks.
- Add vector outlines, embedded export fonts, portable preset libraries, and print dimension controls.
