# Contributing

Run `npm run dev`, `npm test`, and `npm run build` before opening a pull request. For conversion changes, describe how to reproduce the result using a built-in sample or an appropriately licensed fixture. Run `npm run bench` when changing the hot path. Check a desktop and a mobile-sized viewport for interface changes.

Keep image processing in the engine modules. Preserve the worker protocol and versioned project format. Document new algorithms with their inputs, scoring or mathematics, complexity, controls and limits. Cite research and include provenance and licenses for third-party assets.

Include accessibility labels and keyboard behavior when adding controls. In bug reports, share only images you have permission to publish.
